# Halloweekend Quest: A Daily Nebraskan Learning Game

This is a simple command-line board game where you must pass a game of Tic-Tac-Toe against the computer before you can roll for your turn! The game features facts about Halloween costumes from The Daily Nebraskan.

## How to Play

1.  **Prerequisites:** You must have **Python 3** installed on your computer.
2.  **Clone the Repository:**
    ```bash
    git clone [Your Repository URL Here]
    cd Halloweekend-Learning-Game
    ```
3.  **Run the Game:**
    ```bash
    python halloween_learning_game.py
    ```
4.  **Game Rules:**
    * **Tic-Tac-Toe Gate:** Before every roll, you must win a game of Player (X) vs. Computer (O) Tic-Tac-Toe. If you lose or draw, a new game starts immediately until you secure a win.
    * **Movement:** After winning Tic-Tac-Toe, you roll a 1-3 dice to move forward.
    * **Goal:** Be the first to land on or pass the 12th space to win!
