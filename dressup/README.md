# DN Halloweekend Costume Judgment

### Overview
This is a simple, text-based game created for a class assignment. The objective is to test knowledge of costume preferences expressed by writers in recent Daily Nebraskan articles. The player must choose a costume that avoids those deemed "boring and lazy" or "overdone" to win the game.

### Game Goal
[cite_start]Avoid selecting one of the "bad" costumes (e.g., Sports Jersey, Angel/Devil, Kiss/Marry/Kill) to pass the Halloweekend "Judgment" and receive "lots of praise"[cite: 29].

### How to Play
1.  **Prerequisite**: Ensure Python is installed on your system.
2.  **Run**: Navigate to the directory in your terminal and run the file using the command: `python costume_judgment_game.py`
3.  **Choose**: Select a costume number from the list and see if you survive Halloweekend!
